## Family B -- controlled visual occlusion

A seeded rectangular mask (gray, seeded per-event) is painted over the target's box on a **local copy** of the frame image -- the original nuScenes file is only ever opened for reading. ## Reproducibility

Every event records its scene, target track, duration, coverage, RNG seed, the exact mask box, and (for Family B) the detector cache key -- any event can be recreated exactly by rerunning `scripts/build_controlled_events.py` with the same seed.
